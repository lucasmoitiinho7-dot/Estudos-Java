## Conceitos importantes aprendidos

**1. Incrementadores**
- `numero++`: adiciona 1.
- `numero += 2`: adiciona 2.
- `numero += 3`: adiciona 3.

**2. Decrementadores**
- `numero--`: subtrai 1.
- `numero -= 2`: subtrai 2.

**3. Acumuladores**

Utilização de uma variável para armazenar valores acumulados durante um laço.

Exemplo:
```java
soma = numero + soma;
```

**4. Estruturas de repetição**

- `while`: executa enquanto uma condição for verdadeira.
- `do while`: executa pelo menos uma vez antes de verificar a condição.
- `for`: reúne inicialização, condição e incremento em uma única estrutura.
